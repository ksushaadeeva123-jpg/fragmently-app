# fragmently

**Fragmently** — мессенджер, который работает без VPN: переписка, голосовые и видео-звонки, медиа-файлы — всё в одном месте, без блокировок и ограничений.

Задумка одного человека — **Wantergral**. Его идея: сделать мессенджер, который остаётся доступным и стабильным даже тогда, когда привычные сервисы глушат. Дополнительно для устойчивости к блокировкам в приложении есть страница **WhiteList** — конфиг для обхода блокировок, если сервис стали глушить.
